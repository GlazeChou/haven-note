# Haven Note 日常资产宣传卖点

本文整理便签、任务、密钥箱和账本四个日常场景的传播文案，与[笔记与知识资产宣传卖点](./笔记与知识资产宣传卖点.md)共同承接主宣传语：

> 让每一份积累，都成为你的资产。

| 概念 | 宣传标语 | 展开文案 |
| --- | --- | --- |
| **桌面灵感站 · 便签** | **让重要的事留在眼前，不藏在窗口后面。** | 随手记录，把便签钉在桌面，少一次切换窗口，多一分专注。 |
| **时间掌控力 · 任务** | **少一点内耗，多一点完成。** | 安排时间和优先级，看清任务进度，把脑海里的待办变成下一步行动。 |
| **数字身份的归处 · 密钥箱** | **把密码收好，把记忆还给自己。** | 把分散的密码集中管理，需要时快速找到，不再靠记忆硬撑。 |
| **轻记账，深洞察 · 账本** | **不用天天记，也能月月心中有数。** | 每月导入支付宝、微信账单，回看收支与预算；结合资产负债记录，更清楚地规划财务。 |

## 传播重点

- 便签展示桌面置顶和快速查看，突出减少窗口切换。
- 任务展示时间安排、优先级与进度，突出从计划到执行。根据任务是否完成进行语义化智能提醒属于未来规划，不作为当前功能宣传。
- 密钥箱展示集中查找和管理密码；不暗示主密码可以找回，也不把密钥箱的加密范围延伸到其他模块。
- 账本展示每月导入支付宝、微信账单后查看收支，突出无需每天逐笔记录。预算和资产负债应以用户已录入的数据为依据，不暗示自动覆盖所有账户或现金交易。
