# Haven Note 笔记与知识资产宣传卖点

## 主宣传语

> 让每一份积累，都成为你的资产。

以下五个卖点用于介绍 Haven Note 的笔记与知识资产能力。传播时先讲用户获得的价值，再用对应的真实产品操作展示能力。

| 概念 | 宣传标语 | 展开文案 |
| --- | --- | --- |
| **内容主权** | **你的内容，不再寄居于平台。** | 文件留在本地，格式与位置清晰可见。在哪里保存、用什么打开，由你决定。 |
| **自由形态创作** | **一处起笔，让想法自由成形。** | 文字、思维导图、流程图与白板，在同一个创作空间自然切换。 |
| **跨端续写** | **换一块屏幕，接着完成你的事。** | 从电脑到手机，继续编辑笔记与 TXT、源码等文本文档，让工作随你移动。 |
| **行动智能** | **让 AI 从“给建议”，走向“帮你做”。** | 让 AI 读取、创建和修改文档，进入实际工作流程。 |
| **知识复利** | **让每一次记录，成为下一次创造的起点。** | 通过知识库、关联、检索与 AI，让已有积累持续产生新价值。 |

## 传播顺序

首张传播海报使用“你的内容，不再寄居于平台”作为标题，确立内容由用户掌握的立场。后续依次展示全形态创作、跨设备继续编辑、AI 参与操作，以及知识长期积累的价值。每个卖点应配对应平台的真实操作画面。

## 对外表述边界

- “内容主权”聚焦用户直接管理的本地文件；不应由此推断所有应用内部数据都以独立、可见的文件保存，或全部经过加密。
- “跨端续写”以已验证版本的设备、文件类型和同步体验为准。跨设备、跨品牌协同办公是未来愿景，不作为当前已交付功能宣传。
- “行动智能”应以实际可用的文档操作演示，不承诺 AI 能操作软件中的每一个功能。
- “知识复利”表达长期使用价值；涉及 AI 检索或问答时，应展示已验证的效果和适用范围。
