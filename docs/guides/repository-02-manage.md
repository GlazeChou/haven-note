# 2. 建立与管理仓库

> 适用范围：Haven Note 0.1.1-alpha.7。只有界面显示的操作才代表当前平台及仓库支持该能力。

## 第一次创建

1. 首次打开应用时，在欢迎页选择**新建仓库**。以后可打开当前仓库名称的菜单，或进入**仓库管理**，选择**新建仓库**。
2. 在“名称”中输入容易辨认的名字，例如“工作笔记”。查看“位置”和“将创建”的完整路径；若出现**选择保存位置**按钮，可选择新仓库的上级文件夹。
3. 选择**创建**。进入笔记页面后，确认顶部或仓库菜单显示了新仓库的名称。

仓库名称用于辨认；真正需要保留的是仓库所在目录及其中的文件。手机端通常使用应用给出的默认位置，无法选择位置时不要手动修改只读路径框。

## 打开已有仓库

桌面端在欢迎页可选**打开已有仓库**；进入应用后，从仓库名称菜单选择**添加已有仓库**。选择文件夹并按应用提示确认。该按钮仅在当前环境支持选择本地目录时显示。手机端如未显示该入口，不要按照桌面步骤寻找系统文件夹；可先创建本机仓库，再在应用中配置可用的同步方式。

## 切换与定位

- **桌面端**：点击当前仓库名称，从最近打开的列表切换；菜单底部的**管理仓库**可查看全部仓库。支持时可用“打开当前仓库文件夹”在文件管理器中定位。
- **移动端**：点击笔记页顶部的仓库名称进入仓库管理，或从功能导航进入**仓库管理**；选中目标仓库后点**切换**。

切换仓库会改变当前浏览和新建文件的目标。动手编辑前，先确认页面显示的是预期的仓库。

## 管理已有仓库

在**仓库管理**中可以查看名称、位置和最近使用时间。仓库菜单还可能提供**重命名**、**访问密码**、**扫描目录并同步索引**、**显示位置／查看目录**和**从列表移除**。若目录被移动而显示“目录丢失”，桌面端可尝试**重新定位**到原仓库目录。

**从列表移除**是取消应用中的仓库登记，不要把它当作“删除仓库文件”的按钮。执行前仍应查看确认提示；如要清理磁盘上的文件，应先核实实际路径并做好备份。访问密码与磁盘文件是否加密是不同问题，不能仅凭锁图标判断仓库目录中的文件都是密文。
