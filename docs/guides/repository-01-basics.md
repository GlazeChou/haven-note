# 1. 认识笔记仓库

> 适用范围：Haven Note 0.1.1-alpha.7。界面入口会因 macOS、Windows、Android、iOS 而略有不同。

笔记仓库是你选择的一处本地文件空间。仓库中的文件保存在设备上，Haven Note 提供目录浏览、笔记编辑和文件预览；创建仓库本身不要求连接网络，也不会自动把文件上传到服务器。需要跨设备使用时，再单独开启并配置同步。

## 仓库里有什么

| 内容 | 如何理解 |
| --- | --- |
| `.hd` 笔记 | Haven Note 的结构化文档文件，适合在自然编辑器中组织文字、表格、图片和图表。它是普通本地文件，不等同于密钥箱中的加密记录。 |
| `.md` / `.markdown` | Markdown 文件。可以在仓库中打开和编辑，适合已有的纯文本工作流。 |
| 文件夹与其他文件 | 用文件夹整理内容；图片、PDF、电子书、文本和源码等文件按格式进入对应的查看或编辑入口。并非所有格式都能编辑。 |

仓库目录显示的是文件与文件夹；**笔记视图、工程视图是查看分类，不会因为切换视图而移动文件**。识别出工程内容时，界面才会出现工程分类。找不到某个文件时，先检查当前仓库、所在目录及视图分类。

## 仓库笔记与未归档笔记

仓库笔记关联仓库内的 `.hd` 或 Markdown 文件。未归档笔记保存在当前设备的应用数据中，尚未放进仓库目录；它不是仓库文件夹里的一个文件。在手机上，如果当前仓库不支持写入文件目录，新建笔记入口会明确提示保存到“未归档”。

因此，判断一篇笔记是否已经进入仓库，不要只看它是否能在应用中打开：到仓库目录找到对应文件，或查看界面的文件位置。准备删除、换机或清理应用数据前，先确认需要保留的未归档笔记和仓库文件分别在哪里。
