# 4. 整理文件与文件夹

> 适用范围：Haven Note 0.1.1-alpha.7。不同平台和仓库的文件管理能力不同；以操作菜单实际显示与确认提示为准。

## 在目标位置新建

1. 进入**笔记 → 仓库目录**，先选中目标文件夹；需要放在根目录时，回到仓库根目录。
2. 桌面端点击目录上方 **+**，选择**新建笔记**、**新建文件**或**新建目录**。也可以对某个文件夹打开菜单，选择**新建笔记**、**新建子目录**或**新建普通文本**。
3. 移动端点击 **+**，在“新建于当前仓库”中选择**新建仓库笔记 `.hd`**、**新建文本文件**或**新建文件夹**。
4. 完成命名或编辑后，回到目标目录确认新项目出现；若没有，先刷新目录并检查当前仓库。

手机端若显示“此设备暂不支持写入当前仓库的文件目录”，新建笔记会进入**本机未归档**，不会假装已经创建了仓库文件。此时应先处理仓库访问能力。

## 重命名、复制和移动

在目录中打开目标项目的右键菜单或 **…** 菜单。可用操作会随文件类型变化：文件夹及普通文件可能提供**重命名**、**创建副本**、**移动到…**；笔记还可能提供**归档到文件夹…**。移动前先看目标目录，完成后在新位置检查文件。

重命名或移动被其他笔记引用的文件时，应用会尝试同步更新链接；如果出现“链接同步未完全完成”，应检查提示列出的文档和原有引用。文章引用的资源路径受到保护时，相关移动、重命名或删除操作可能被拒绝，不要绕过保护后假定引用仍有效。

## 删除前确认

目录菜单可能提供**删除**或**删除目录**。先确认选中的是文件、整个文件夹，还是多选的一组项目；文件夹可能包含当前没有展开的内容。按照界面确认提示操作，并在删除前为重要文件保留副本。关闭编辑标签或“从仓库列表移除”都不是删除仓库文件。

如果菜单中没有某项操作，说明当前文件类型、仓库状态或设备尚不支持该操作。下一篇：[编写仓库笔记](repository-05-edit.md)。
