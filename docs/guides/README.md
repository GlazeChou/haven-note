# 操作指南

此目录用于安装入门和各功能的操作步骤。指南会注明适用的平台与版本；平台操作有差异时分别说明。

## 笔记仓库

按顺序阅读，也可以直接打开需要的操作：

1. [认识笔记仓库](repository-01-basics.md)：仓库文件、笔记格式与未归档笔记。
2. [建立与管理仓库](repository-02-manage.md)：创建、打开、切换和管理仓库。
3. [浏览仓库](repository-03-browse.md)：目录、视图、搜索、最近使用与排序。
4. [整理文件与文件夹](repository-04-organize.md)：新建、重命名、复制、移动和删除。
5. [编写仓库笔记](repository-05-edit.md)：新建 `.hd`、打开 Markdown、保存、预览与处理版本差异。

其余功能指南会在核对发布版本的实际操作后陆续添加。
