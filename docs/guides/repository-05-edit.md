# 5. 编写仓库笔记

> 适用范围：Haven Note 0.1.1-alpha.7。本篇只讲仓库中的笔记；复杂编辑器组件会另写专题。

## 新建一篇 `.hd` 笔记

1. 进入**笔记**，核对顶部显示的仓库名称。
2. 在仓库目录选定放置位置，点击 **+ → 新建笔记**；手机端对应**新建仓库笔记 `.hd`**。
3. 输入标题和正文。可以先用段落、标题和列表组织内容，再根据需要插入表格、图片、附件或图表。
4. 查看保存状态，回到仓库目录确认文件出现。再次打开文件，检查标题与正文是否仍在。

`.hd` 是结构化的本地文档文件，适合使用自然编辑器。普通 `.hd` 内容不要当作加密的秘密存储；密码和密钥应放在独立的密钥箱。

## 打开已有笔记

在仓库目录点击 `.hd`、`.md` 或 `.markdown` 文件。Haven Note 会根据格式进入相应编辑体验；不要为了在应用中查看而擅自改文件扩展名。桌面端可同时打开多个文件，通过上方标签切换；关闭标签只是关闭编辑视图，不等于删除文件。

如果移动端将笔记显示在**未归档**，它尚未对应仓库目录里的文件。只有在仓库支持文件写入并完成相应归档操作后，才应把它视作仓库笔记。

## 保存、预览与导出

编辑关联仓库文件时，应用会尝试自动保存到原文件。离开前检查是否仍显示**未保存／等待保存／正在保存**；桌面端需要时可从文件菜单选择**保存原文件**。桌面端的**保存并预览笔记**可以切换阅读视图；导出菜单提供 PDF、Markdown 和 Word 选项，具体可用性以当前文档和平台为准。导出生成的是另一份文件，不会自动替换仓库中的原文档。

如果出现**发现版本差异**，表示当前文档和磁盘文件都有更改，自动保存会暂停。点击**查看差异**，先决定保留哪一版；不要通过反复关闭、重开或覆盖文件来消除提示。若仓库路径已不可用，先恢复仓库访问，再处理未保存内容。

## 写作时的建议

- 先用标题和小节建立结构，再插入图片、表格等内容；文档较长时便于阅读和查找。
- 引用其他仓库文件后，移动或重命名目标文件应查看链接更新提示。
- 重要内容除检查保存状态外，还应按自己的备份方式保留仓库目录副本。
