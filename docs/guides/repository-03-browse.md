# 3. 浏览仓库

> 适用范围：Haven Note 0.1.1-alpha.7。以下介绍浏览与定位；文件修改见[整理文件与文件夹](repository-04-organize.md)。

## 找到目录

先进入**笔记**，确认当前仓库名称。桌面端的仓库目录通常在笔记侧栏；点击文件夹展开，再点击文件打开。目录上方的 **+** 是“新建仓库内容”，**…** 中可刷新目录、展开／折叠文件夹，或切换是否显示资源目录。正在编辑某篇仓库文档时，可使用**定位当前文档**回到它在目录中的位置。

移动端底部选择**仓库目录**。进入文件夹后，可继续打开子文件夹或文件；顶部搜索用于查找标题与文件，在子目录中也可搜索当前目录。若页面显示“正在读取仓库文件”或读取失败，先等待或点击**刷新**，再判断文件是否缺失。

## 笔记、工程、未归档

仓库包含工程内容时，可能出现**笔记**与**工程**分类：前者集中呈现笔记文档，后者显示源码及配置等工程文件。移动端还能在同一区域切换**未归档**，查看尚未成为仓库文件的本机笔记。分类只是浏览方式，不会修改文件路径，也不会自动把未归档笔记放进仓库。

如果在“笔记”里找不到 `.ts` 等源码文件，请切换到“工程”；如果在仓库目录中找不到本机草稿，请检查“未归档”。不是工程仓库时可能不显示“工程”入口。

## 最近使用与排序

移动端底部的**最近使用**列出最近打开的仓库文件，点击可直接返回文件。桌面端也有最近笔记入口。它是快速访问列表，不是独立的存储位置；从这里打开文件后，仍可回到仓库目录查看其路径。移动端目录提供排序按钮，选择需要的排序方式即可；排序不重命名或移动文件。

## 列表与实际文件不一致时

1. 核对当前仓库和“笔记／工程／未归档”分类。
2. 展开目标文件夹，必要时显示资源目录，或用搜索查找文件名。
3. 使用**刷新目录**；仓库管理中的**扫描目录并同步索引**用于重新扫描目录与索引。
4. 若界面提示目录不可用或当前设备不支持浏览该仓库文件，先处理仓库位置或平台能力，不要反复新建同名文件。

目录项目超过 10 万时，列表可能只显示已扫描的一部分。下一篇：[整理文件与文件夹](repository-04-organize.md)。
